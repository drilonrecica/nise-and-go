# Public Roadmap

This roadmap communicates direction, not dates or delivery promises.

## V0.1 — Golden foundation

- Deterministic `nise` CLI and project creation.
- Typed runtime configuration and structured errors.
- PostgreSQL, pgx, sqlc, Goose, and transaction conventions.
- Strict OpenAPI API boundary and generated TypeScript client.
- Session authentication, authorization, CSRF protection, and audit records.
- Complete Svelte 5 authenticated application shell and generated resources.
- PostgreSQL-backed jobs, email, files, and notifications.
- CI, security scanning, fuzzing, and performance baselines.
- OCI release, Coolify recipe, backup, and restore verification.
- Realistic reference business application.

## Validation

- Freeze framework features.
- Build POS Kosova against Nise.
- Correct deficiencies backed by real evidence.
- Build a smaller second application.
- Complete an upgrade cycle.

## V1.0

V1.0 begins stable public runtime compatibility only after validation requirements are met.

## Later possibilities

A separately designed Go + chi + HTMX + SQLite profile may follow. Additional combinations are not promised.
