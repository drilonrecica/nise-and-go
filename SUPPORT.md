# Support

Nise & Go does not provide commercial support, guaranteed maintenance, or a response SLA.

## Use GitHub issues for

- Reproducible defects.
- Documentation mistakes.
- Focused proposals that fit the golden profile.
- Questions that expose a concrete documentation gap.

## Do not use GitHub issues for

- Private security reports; use the process in [SECURITY.md](SECURITY.md).
- General Go or Svelte support.
- Requests to support unrelated routers, databases, or frontend stacks.
- Urgent production incidents requiring guaranteed assistance.
- Large feature requests without a real application use case.

An unanswered issue is not a promise that the project will address it later.
